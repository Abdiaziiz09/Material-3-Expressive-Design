# Anti-patterns

- Claiming `useMaterial3: true` means M3 Expressive is fully implemented.
- Treating every Material component as having a verified Expressive variant.
- Inventing token values, corner radii, breakpoints, motion timings, or state behavior.
- Treating screenshots or community packages as normative sources.
- Using hard-coded colors throughout instead of semantic roles and theme configuration.
- Assuming one phone layout works unchanged across phones, tablets, foldables, and split-screen states.
- Ignoring text scaling, RTL, keyboard focus, semantics, or platform accessibility.
- Adding decorative motion that blocks input or has no reduced-motion consideration.
- Describing untested Android/iOS versions or device form factors as supported, or claiming unverified compliance.
- Copying proprietary images, source prose, or design assets without rights.
